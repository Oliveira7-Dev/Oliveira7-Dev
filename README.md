## 🚀 Projeto em destaque — ProjectFlow

**ProjectFlow** é uma aplicação web de gerenciamento de projetos e tarefas desenvolvida com Flask.

### ✨ Principais recursos

- 🔐 Cadastro e autenticação de usuários
- ✉️ Verificação obrigatória de e-mail
- 🔑 Recuperação de senha por e-mail
- 🛡️ Proteções de segurança, CSRF e rate limiting
- 🔒 Política de senhas fortes e medidor de força
- 👤 Configurações de perfil e alteração segura de senha
- 📁 Criação e gerenciamento de projetos
- ✅ Gerenciamento de tarefas
- 📊 Acompanhamento automático de progresso
- 🔎 Filtros por status, prioridade e prazo
- 📱 Interface responsiva para desktop e celular
- 📲 Recursos de PWA
- 🐘 PostgreSQL em produção
- ☁️ Deploy em ambiente cloud
